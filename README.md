# Jogo do Número Secreto 🎮🔢

**Descrição**  
O **Jogo do Número Secreto** é um jogo simples e divertido que desafia o jogador a descobrir um número aleatório gerado pelo computador, com base em pistas de maior ou menor. Ele foi desenvolvido com o intuito de treinar lógica de programação e fundamentos de desenvolvimento de jogos, inspirado nos cursos da **Alura** e da **One Oracle Education**.

---

## ⚡ Funcionalidades

- **Geração de Número Aleatório:** O jogo escolhe um número aleatório dentro de um intervalo especificado.
- **Interatividade:** O jogador tenta adivinhar o número, recebendo feedback a cada tentativa.
- **Dicas:** O jogo informa se o número fornecido é maior ou menor do que o número secreto, ajudando a refinar as tentativas.
- **Desafio Progressivo:** O número máximo de tentativas é limitado, aumentando a dificuldade conforme o progresso do jogador.

---

## 🚀 Como Jogar

1. O computador escolhe um número secreto dentro de um intervalo definido (por exemplo, de 1 a 10).
2. O jogador deve tentar adivinhar qual é o número secreto, enviando sua tentativa.
3. O computador responde se o número informado é **maior** ou **menor** do que o número secreto.
4. O objetivo é acertar o número dentro do número limitado de tentativas.
5. O jogo termina quando o jogador acerta o número ou fica sem tentativas.

## 🎯 Objetivo do Projeto

Este projeto tem como objetivo reforçar os conceitos de:

- Geração de números aleatórios.
- Estruturas de controle (como loops e condições).
- Interatividade com o usuário.
- Processamento de entradas e saídas.
